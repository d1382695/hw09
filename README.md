## 一、程式用途與執行方式

### 程式用途
本程式用於整理「桌遊體驗」與「電影欣賞」兩場活動的原始文字報名名單。透過字串清理方法（去除半形空白、統一轉小寫、逗號分割）將文字轉為串列，並搭配 `tuple`、`list`、`set`、`dict` 等 Python 內建資料型別完成以下任務：
1. 保留原始整理順序（`list`）以供檢視重複報名紀錄。
2. 利用集合（`set`）去除同一場次內的重複報名，並透過交集、聯集與差集比對兩場參加者重疊狀況。
3. 依字母順序排序名單，利用切片取得通知名單前兩位。
4. 使用字典（`dict`）查詢單價與彙整人數、人次及各場應收金額，最後以 `f-string` 格式化輸出完整摘要。

## 三、問題回答

### 問題一：測試一中，整理後的桌遊串列有 4 筆資料，為什麼桌遊費用應以 3 人計算？直接把字串拆成 list，和再轉成 set，各自保留了什麼、失去了什麼？
- **計費原因**：因為 `"Amy"` 與 `"amy"` 在統一轉小寫並去除空白後皆為 `"amy"`，屬於同一位報名者重複送出表單。根據活動規則，同一人在同一場活動重複出現只算一位參加者、只收一次該場費用，因此扣除重複後實際參加桌遊的人數為 3 人（`amy`、`ben`、`cora`），費用為 `3 × 120 = 360` 元。
- **`list` 與 `set` 的差異**：
  - **直接拆成 `list`**：**保留了**原始報名的先後順序，以及重複報名的次數紀錄（可用來追蹤誰重複填單）；但**失去了**自動識別唯一參加者的能力，若直接用長度計費會發生重複收費。
  - **再轉成 `set`**：**保留了**不重複的唯一參加者元素，並獲得交集、聯集、差集等集合比對功能；但**失去了**原本的報名先後順序以及重複出現的次數資訊。

### 問題二：測試三中，兩場活動只有 3 位不同的人，為什麼是 6 人次、總應收仍是 600 元？請用集合關係與算式說明。
- **集合關係**：在測試三中，桌遊集合 $A = \{\text{'amy'}, \text{'ben'}, \text{'cora'}\}$，電影集合 $B = \{\text{'amy'}, \text{'ben'}, \text{'cora'}\}$，兩者元素完全相同（$A = B$）。因此兩者的聯集 $A \cup B = \{\text{'amy'}, \text{'ben'}, \text{'cora'}\}$，元素個數 $|A \cup B| = 3$，代表總不重複人數只有 3 人；兩者的差集 $A - B$ 與 $B - A$ 皆為空集合 $\emptyset$。
- **人次與金額算式**：因為「報名人次」與「應收費用」是依兩場活動各自去重後的參加人數分別累計（同一人參加兩場需分別支付兩場費用）：
  - **報名人次** $= |A| + |B| = 3 + 3 = 6\text{ 人次}$
  - **總應收金額** $= (|A| \times 120) + (|B| \times 80) = (3 \times 120) + (3 \times 80) = 360 + 240 = 600\text{ 元}$
